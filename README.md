
# Focus30 – Daily Discipline & Life Routine Analyzer

Focus30 is a web application designed to help users build discipline over a 30-day period. It allows users to log their daily activities, track positive and negative habits, and visualize their progress through a comprehensive analytics dashboard.

## Features

-   **User Authentication**: Secure sign-up and login functionality using Firebase Authentication.
-   **Profile Setup**: A personalized onboarding experience for new users to set their name, age, and primary goal.
-   **Daily Habit Logging**: An intuitive interface to log various activities throughout the day, categorized into morning, daytime, evening, and night routines.
-   **Scoring System**: Each daily log is automatically scored based on completed habits to provide immediate feedback.
-   **Analytics Dashboard**: Visualize progress with interactive charts showing trends in daily scores, habit completion percentages, and time allocation.
-   **Responsive & Dark Mode**: A sleek, modern, and fully responsive dark-mode UI for a great user experience on any device.

## Tech Stack

-   **Frontend**: React, TypeScript, Tailwind CSS
-   **Backend & Database**: Firebase (Authentication, Realtime Database)
-   **Routing**: React Router
-   **Charts**: Recharts
-   **Notifications**: React Hot Toast
